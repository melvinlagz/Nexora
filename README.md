# Nexora

Nexora is a landing page for an independent digital studio based in Nairobi, Kenya — built with plain HTML, CSS, and JavaScript. It showcases the studio's services, approach, and a contact section, with a modern, animated single-page design.

> Technology that moves business forward.

## Tech Stack

- HTML5
- CSS3 (custom styles, no framework)
- Vanilla JavaScript

## Features

- Responsive single-page layout with a sticky header and mobile nav toggle
- Animated hero section with orbit/signal graphics
- Sections for:
  - **Solutions** — Digital products, Brand systems, Intelligent operations
  - **Approach** — a 3-step process (Find the signal → Make it tangible → Keep it moving)
  - **About** — studio introduction
  - **Contact** — direct email link and location
- Custom typography via Google Fonts (Manrope, DM Mono)

## Getting Started

This is a static site with no build step required.

1. Clone the repo:
   ```bash
   git clone https://github.com/melvinlagz/Nexora.git
   ```
2. Open `index.html` in your browser, or serve the folder with any static server, e.g.:
   ```bash
   npx serve .
   ```
